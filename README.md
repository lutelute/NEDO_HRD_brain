# NEDO HRD Brain 🧠⚡

**NEDOプロジェクトを核とした人材育成、産学連携等の総合的展開／将来の電力システムの計画・運用を支える人材育成**

*NEDO Project for Comprehensive Development of Human Resource Development and Industry-Academia Collaboration / Human Resource Development for Planning and Operation of Future Power Systems*

---

## 🌐 **Web Site**

**🔗 Live Site**: [https://www.nedo-hrd.online/](https://www.nedo-hrd.online/)

## 📋 **概要 / Overview**

このリポジトリは、将来の電力システムの計画・運用を支える人材育成を目的とした知識ベースです。NEDOプロジェクトの成果を中心に、電力系統に関する研究テーマ、教材、ワークショップ資料などを体系的に整理・公開しています。

*This repository serves as a knowledge base for human resource development in future power system planning and operation. It systematically organizes and publishes research themes, educational materials, and workshop resources centered on NEDO project outcomes.*

## 🗂️ **構成 / Structure**

```
📁 テーマ集/
├── 📁 01_研究テーマ-研究ソース/     # Research themes and sources
├── 📁 02_年度成果/                 # Annual achievements  
├── 📁 03_map/                     # Knowledge maps
├── 📁 04_人材育成_教材/             # Educational materials
│   ├── 系統解析モデル/             # Power system analysis models
│   └── 解析ツール/                 # Analysis tools (MATPOWER, PandaPower)
├── 📁 05_ワークショップ/            # Workshop materials
├── 📁 07_文献_PDF_etc/            # Literature and documents
├── 📁 08_その他/                  # Other resources

```

## 🚀 **使い方 / How to Use**

### **Web ブラウザでアクセス**
最新の内容は常に **[https://www.nedo-hrd.online/](https://www.nedo-hrd.online/)** で確認できます。

### **ローカル環境での利用**
1. リポジトリをクローン:
   ```bash
   git clone https://github.com/lutelute/NEDO_HRD_brain.git
   ```

2. Obsidian で開く:
   - [Obsidian](https://obsidian.md/) をダウンロード・インストール
   - "Open folder as vault" で `テーマ集/` フォルダを選択

3. 推奨プラグイン:
   - **Excalidraw** - 図表の表示・編集
   - **Dataview** - データベース機能
   - **PDF++** - PDF ファイルの表示
